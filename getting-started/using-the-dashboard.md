# Using the Dashboard

Once your account is registered, you can use the PiCapes Dashboard to manage your capes, view account information, and access available dashboard features.

## Accessing the Dashboard

To sign in, run the following command in the `#⚡・machine` channel:

```text
/login
```

PiCapes will send you a private dashboard login message containing a secure sign-in link.

![/login Message](/assets/docs/screenshots/dashboard_message.png)

Click **Login to Catalog Dashboard** to continue.

After clicking the link, you will be prompted to authorize your account via Discord OAuth then will be redirected to the PiCapes Dashboard and automatically signed in.


<!--::: warning ⚠ Important
Dashboard login links are tied to your account and should never be shared with anyone else. If accidently shared, Running `/login` again will invalidate any previous dashboard login session and generate a new login link.
:::-->
